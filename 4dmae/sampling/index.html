What is sampled?

B1 · fixed object surfaces

  1. Seed 42 defines 64 material points on each object: cube and L-shaped tool.
  2. Choose exterior faces in proportion to area; sample uniformly inside each face.
  3. Per object, IDs 0–31 belong to C and 32–63 to Q. B1 reads only Q: 32 + 32 = 64.
  4. The point bank is fixed across episodes, windows and epochs. Simulator object poses provide future trajectories.

No visibility filter, background, arm or gripper sampling. Stored C tracks are unused by B1.

B5 · visible scene / object holdout

  1. Choose one eligible target uniformly: cube, tool or gripper.
  2. Choose 3 target Q with part coverage / geometric spread, plus 9 stratified Q outside the target.
  3. Choose 12 scene C from the global pool, excluding Q, round-robin over randomly ordered grid cells.
  4. For holdout, replace target C with points outside the target. Keep all Q and the other C unchanged.

Random key: seed, epoch, episode, tick and operation. Points keep their material identities within the window. No DINO sampling is used.

How the data is organized

1,000 expert demonstrations → 897 train / 103 validation episodes → 200,207 / 22,458 windows. A window starts at each eligible control tick; the final 31 action starts are omitted to keep a complete 32-action chunk.

SceneDataset constructs C/Q and their labels at loading time. The 352 candidate slots per tick are padded with invalid pixel IDs; they are not 352 model input points.

B1 and B5 inherit the same RGB, state, actions and split identities. B5 stores the candidate pool once; each training epoch draws another C/Q set from that pool. Validation uses epoch 0. A deterministic global permutation and explicit (index, epoch, mode) keys preserve sampling across resume.

Scope and provenance

This page inspects the latest completed 50k runs: B1 8cfd8df, B5 b537131. A newer 200k recipe is prepared but had not started in its delivery record; its point sampling is unchanged.

The examples are exported from the production train split using the frozen B5 sampler. Epochs 1 and 2 show deterministic loader outputs for the same windows, not logged optimizer batches. The batch grid reconstructs the first training batch. B1 and B5 differ in both history input and trajectory supervision; this is not a single-factor ablation. No training, model inference or physics stepping was performed for this page.

The earlier preview used one demonstration, optional DINO diversity and longer history clips. It remains archived as a sampling prototype; it is not the current training dataset.
