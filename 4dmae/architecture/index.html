Configuration and implementation notes
Shown: PullCubeBase B5 defaults
Robot state918
Action chunk32 × 840 × 7
Trajectory points64 C + 64 Q64 C + 64 Q
History / displacement slots16 / 3016 / 30

C denotes points with observed history; Q denotes additional points with current anchors only. PullCube supplies privileged simulator history. The input history includes the current frame; its displacement is zero and is omitted from the 30 output slots.

The action and trajectory heads are flow-matching models. Training losses supervise velocity fields, while sampling integrates them for 50 Euler steps. The trajectory decoder is called separately for C and Q; action inference does not call it. Learned future queries remain in the HPT during action inference.
