读图时最容易混淆的地方

  1. 128 个 HPT token = 64 action query + 16 future query + 16 RGB + 16 state + 16 history。64 个动作条件 token 最终生成 40 步动作。
  2. 共享发生在两处：观察输入与 C/Q decoder 输入共用 Tθ；C 与 Q 的两次解码共用 Dφ。三个辅助 loss 并不对应三个独立 head。
  3. 推理动作无需先预测轨迹。动作与轨迹头分别读取同一个 HPT 的不同 context。未来 query 是学习向量；标签不会进入观察编码器。
  4. 一个点是一整个轨迹 token。15 过去与 15 未来槽展平后编码；decoder 的 self-attention 在点间进行。

训练监督与轨迹推理

L = Laction + (LC future + LQ past + LQ future) / 3

C 的已知过去在生成过程中固定，Q 只提供当前 anchor。训练时未知轨迹槽从 clean target 与 Gaussian noise 插值，学习 noise − clean 速度；推理从噪声做默认 50 步 Euler 积分。输出为相对 anchor 的米制位移；当前时刻位移隐含为零。所有标签 mask 用于监督，不作为真实未来信息传入主干。
