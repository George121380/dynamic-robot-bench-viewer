# 移动相机下的 3D flow：交互几何示意

已完成三个场景的动画，比较未补偿、理想补偿和带误差的补偿。所有数值来自受控几何，未运行真实 human 视频、Track4World 标签提取或已部署预测头；不能用本页声明其实际精度。

源片段为 `moving-camera-flow.html`，`index.html` 是包含样式和本地状态存储的独立页面。在线地址：https://peiqil.com/dynamic-robot-bench-viewer/egowam/flow-motion/ 。场景选择、时间滑块及单次三秒播放均在浏览器内计算，无外部请求。

物体右移 8 cm、相机右移 10 cm 时：未经补偿的物体横向位移为 −20 mm，理想补偿为 +80 mm；假设两帧点坐标共同放大 20%，同时用米制相机平移补偿，则静止背景残余为 20 mm，物体估计位移为 +76 mm。仅有相机转头 15° 时，初始距离 0.7 m 的静态点未经补偿位移约 182.7 mm；理想补偿为零；额外假设相对旋转多估计 1°，残余约 12.2 mm。这些误差假设并非 Aria 或 Track4World 的实测误差。

绘图是 y=0 的 x–z 三维切片。三个图统一使用初始参考点和等比例坐标，箭头放大三倍；数值栏显示真实计算量，不乘三。尺度错误图绘制的是错误估计的位移向量，而非将归一化点云宣称为米制绝对位置。

Chrome 已验证默认状态、旋转场景、滑块 0% / 50%、播放开始和自然结束；320 px 页面不出现横向溢出，坐标标签大于 11 px；宽屏并排、窄屏堆叠。动画遵守 reduced-motion，不自动循环。页面内脚本语法检查通过。真实数据验收仍需未过滤静态背景的残余分布和独立动态三维真值。
