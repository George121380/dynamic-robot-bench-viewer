# 汇报用英文论文风格架构图

已绘制两张16:9矢量图，描述当前实际训练过的架构。主图展示完整策略与训练期补全，细节图展示轨迹编码、点采样、五组基线以及3NN补全残差的connected/detached对照。图内全部为英文，使用蓝色RGB/策略、青色轨迹、橙色训练分支的统一配色。

`architecture-overview`适合作为主汇报页，`architecture-details`用于下一页或备份页。每张均提供可编辑SVG、矢量PDF及4800×2700高清PNG；`architecture-figures.pdf`合并为两页，`architecture-figures.zip`包含全套导出与说明。画中衣服、相机和输出曲线均为示意，不是新仿真结果。英文图注和完整来源见README.md。

代码连接已逐项核对：原ACT保留当前完整空间特征；其余方法使用相同16帧RGB历史；点MLP按每点16×8展开并共享权重；补全读取主ACT注意力之前且排除posterior latent的观测token；hidden点只作训练query/标签；3NN残差加在补点预测上，未画成动作残差。验证MSE直接针对反归一化的关节目标，单位rad²。

这些图没有加入后续讨论但尚未实现的动作残差融合或门控方案，也没有声称当前方法已获得性能提升。GT轨迹为仿真特权信息。此次仅在本地绘图和导出，没有新训练或GPU任务。
