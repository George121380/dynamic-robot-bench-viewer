已验证的模型边界

  • 改变轨迹历史，动作输出会改变。
  • 隐藏目标、辅助 query 不进入 actor。
  • 未来专家动作不能改变历史补全。
  • 辅助损失的梯度到达共享观测编码器。
  • 空轨迹、冷启动和 NaN padding 不污染输出。
  • 四组模型使用相同初始化和模块。
  • 点顺序不作为语义身份编码。
  • 在线历史缓存与离线窗口一致。
  • 模型 checkpoint 与动作队列可恢复、重置。
  • 删除整个辅助头，动作输出保持完全相同。
