What this experiment shows

The current adaptation does not reliably predict multi-object collisions. All-pin error is 2.30 cm, versus 1.42 cm for a stationary baseline.

On the training trajectories, the selected model detects only 2/472 tipped pins. An eight-episode overfit diagnostic detects 18/21. This points to an unresolved training problem; it does not establish the model’s capability limit.

5,000 AdamW updates; checkpoint 4,750 selected using validation only. All model baselines receive identical corrected inputs and sparse-convolution handling. Original object sizes and physics are unchanged; no rigid-body correction is applied to forecasts. Repairs cover RGB-D alignment, voxel correspondence, action timing, normalization and duplicate sparse indices.

ADE is average displacement error over the 10 future frames. Pin error is averaged per object. Tip detection uses fitted point rotations; it detects 62/62 tips on ground-truth points. Static false motion means >2 cm predicted movement. Training-set checks use fixed sampling; the eight-episode diagnostic weights were discarded.

One training seed and exact simulated depth. Final test forecasts use verified FP32 reference inference; original BF16 validation selection and weights are unchanged. Independent restoration and all 116 saved forecasts were checked. Numerical inference and portable sampling corrections were applied after the first test evaluation; no additional training or test-based selection followed.

All 29 valid tests are available, including misses. One of 30 attempts had no robot–ball contact and no prepush query. The default is the lowest seed with at least three true tipped pins, chosen independently of model performance.
