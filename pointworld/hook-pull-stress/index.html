Results and metric definitions

Point error is the distance between predicted and true object points. Mean error averages the 10 future frames; final error uses the frame at 2 s. Lower is better. Tool and table points are excluded.

Conditions and evaluation notes

Geometry: independent hook proportions, cuboid dimensions (2.6–7.2 cm), orientation (±20–65°), and approach gap. Action: oblique pulls, speed ramps, pauses, reversal, and lateral sweeps. Combined: geometry + action + mass (12–400 g), friction, and restitution.

All 17 unscored cases: native images and input-quality reasons

Action labels describe intended controls; actual outcomes remain in the recorded trajectories. The model receives only the current observation and committed tool plan. Future observations, physical parameters and labels are excluded from its input. Brown executed-hook points are used only for visualization.

Forecast points are unchanged: no smoothing or rigid-body correction. All cases share fixed world bounds. This is exploratory stress evaluation; planned versus executed tool motion and hidden physics remain possible error sources.
