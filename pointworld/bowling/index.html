设置与证据 / Setting and evidence

先完整运行专家以记录动作提案，再从相同初态冻结执行。输入是推动前的一次同步双视角真值 RGB-D、标定、当前机器人状态，以及已冻结的未来动作；本实验是给定动作计划的预测，不能说明模型能自行提出有效动作。未来机器人点由关闭接触的机器人模拟器积分得到，不使用未来真实球／球瓶／机器人轨迹。被动物体身份只用于监督和评分；当前渲染的机器人分割用于去除机器人像素，是本轮的辅助假设。

固定 whole-seed 划分，测试未用于训练或 checkpoint 选择。训练从原始 small-DROID 开始，冻结 DINOv3，保留 DROID 归一化。训练以 50% 概率抽取运动轨迹，另 50% 抽取静止轨迹；按验证集运动球瓶 ADE 选 checkpoint。

这是新采 CPU MuJoCo 轨迹的点预测实验，未复现官方 MJWarp 数据集成绩，也没有执行 PointWorld 规划策略。只评价两秒窗口；不能把此处倾倒瓶数当作完整十秒任务得分。固定物理参数、小样本、单次训练种子，尚未验证质量／摩擦泛化或真实深度噪声。

80 次尝试中 2 条没有手–球接触，无法定义 prepush 查询而排除；其余 78 条保留，包含未击倒球瓶的轨迹。所有轨迹从冻结动作重放，qpos 与原执行逐步一致。环境有不可见边界，但本轮两秒窗口内未记录球／球瓶与该边界的接触。固定随机种子不能保证 PointWorld 的 GPU 前向逐位一致；本页展示一次实际保存的评测。
