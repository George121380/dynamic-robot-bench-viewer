这轮到底验证了什么 / Protocol boundaries

这是点运动预测的迁移实验，不是机器人策略成功率评测，也不是完整 Benchmark 复现。只看当前一帧，没有物体历史或隐含速度输入；质量、摩擦、未来真实机器人轨迹、接触与成功标签均不进入模型。

RGB-D 反投影产生当前可见点。真值位姿只在监督侧关联／运输这些点，未提供隐藏表面 Oracle 点。蓝色 peg 的当前像素是执行器代理；未来工具点由预提交控制请求积分，包含控制器执行误差，不使用未来实测工具轨迹。单视角、已知蓝色工具外观，是此 adapter 的限制。

按 domain/family/seed 整组划分，基础与独立参数版本、各模式与重复采集不能跨 split。同初态＋同指令的重复样本去重。缺 RGB-D 的旧文件排除；OOD 没有训练使用。Frame 0 显示共同当前观测，之后展示实际保存的网络预测。

冻结 DINOv3，微调其余原模型参数，保留 DROID 归一化统计。没有增加物理引擎、手写碰撞规则或预测后刚体修正。模型没有 contact head，contact onset/release 指标为 null。样本量较小，请结合失败模式和 OOD 阅读。

本页是保存的单次评测结果。固定序列化随机种子后，物体点重复 GPU 推理仍有毫米级差异，含桌面背景的单点差异最高约 1.97 cm；严格权重重载和输入一致性通过，逐位预测一致性未通过。Residual GPU forward variability remains; bitwise prediction reproducibility is not claimed. A/B/C 的物理参数在每条新采轨迹内共用；尚未验证独立质量比泛化。本页评价窗口内固定的可见深度像素点，不是原始 12 个 Oracle 点的直接可比成绩。
