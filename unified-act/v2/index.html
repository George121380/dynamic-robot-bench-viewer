UNIFIED-ACT-V2 · REVIEW HARDENING

尽量少改 ACT，把额外逻辑放在外围

标准 ACT 条件直接调用上游 ACT.forward()。扩展条件只追加历史 tokens、融合点 memory；当前图像编码、CVAE、action decoder、动作头和 L1+10KL 保持原生。没有运行时 hooks、monkey patch 或另一套手写 ACT 前向。

CPU 回归 与原生对齐真实任务训练 未启动核心上游 LeRobot 0.4.3完整修改 patch

01 / What is actually changed?

原生路径保留

单帧条件：wrapper → super().forward(batch) → 原 ACT。构造函数、参数形状、posterior采样、当前图像编码和动作头均沿用原实现。

测试会核对固定上游源码、保存的原文和扩展patch；升级上游时必须重新审查这份小差异。

仅两处条件扩展

① encoder 前追加因果 RGB 历史 tokens。
② encoder 后做一次轨迹 token cross-attention。
点头另有 z=0 memory 读出，隔离未来动作 posterior；不改动作生成器。

v2删除沿轨迹图像采样、点视觉投影、标定依赖和隐藏辅助随机计数器。

02 / The minimal point branch

数值轨迹：[current XYZ, past displacement, physical time, valid] → 共享 MLP → 一次点融合。Stationary 与 Tracks 保留同样RGB、锚点、mask、时间、参数；只改变数值位移。当前点历史仍是包含过去遮挡位置的 oracle persistent vertices，没有实现真实tracker。

04 / Fair comparison stays explicit

先比较 ACT、ACT-H、Stationary、Tracks，aux均OFF。相同数据分组、统计、ACT初始化、预训练视觉权重、样本顺序、batch、optimizer、precision、更新预算、验证选模和执行前缀。相同步数不代表相同算力，同时报告墙钟、显存和延迟。

OFF/detached 使用普通PyTorch backward与AdamW，actor/head分开clip。可选bounded研究隔离在独立模块；0.1是全局原始共享梯度范数比，不能解释为Adam更新或每个模块的10%。不自动启动shared实验。

原生 ACT 的训练目标仍是 normalized padded L1+10KL。验证记录最终反归一化、prior0、排除padding的 raw action chunk MSE，以及首动作、逐维MSE和单位；不是速度场误差。
