第一轮：整条点历史 Mask 如何工作？

每个物体有 6 个查询点，共 12 点。B / C 对每个点独立以 50% 概率遮蔽过去整条轨迹，保留当前点位置和当前 RGB。C 额外学习补全隐藏的过去；未来预测头不读取补全输出。

真实原数据与原 C checkpoint（seed 7，更新 1800）；本页只做 CPU 前向推理，没有新增训练。点的历史由精确物体位姿构造，人工 mask 与相机遮挡是两种不同情况。

实现细节

随机键与数量

SHA256(sample_id:epoch:seed) 的前 8 字节生成独立 NumPy RNG。12 次 Bernoulli(0.5)，因此每个样本不一定恰好遮蔽 6 点。若全部 12 点被隐藏，随机恢复 1 点；没有按物体分别保底，也没有强制至少隐藏 1 点。

遮蔽范围与保留信息

hidden 形状是 [batch, 12]，广播到 [batch, 12, 10, 3]。选中点的 −1.0…−0.1 秒历史位移全部置零，在 GRU 和跨点 Transformer 之前完成。P0、当前视觉锚点、全局 RGB 特征、机器人状态、时间网格和未来动作保留。

A / B / C 的差别

A 训练时不 mask，只优化未来 loss。B 与 C 使用完全相同的 sample / epoch / seed mask；B 只优化未来 loss，C 加 1.0 × 隐藏历史 loss。历史 loss 只覆盖 hidden 且 valid 的负时间标签，工具与方块均参与。

训练与测试

训练 seed=7，数据每过一轮 epoch 增加，mask 随之变化；B / C 记录的完整 mask hash 相同。验证选 checkpoint 与主测试都输入完整历史；缺失历史补充测试固定 epoch=0、seed=12345。

原函数与输入处理

def deterministic_mask(sample_id, epoch, seed, n=12, probability=.5):
    digest = hashlib.sha256(f'{sample_id}:{epoch}:{seed}'.encode()).digest()
    rng = np.random.default_rng(int.from_bytes(digest[:8], 'little'))
    hidden = rng.random(n) < probability
    if hidden.all():
        hidden[int(rng.integers(n))] = False
    return hidden

history = torch.where(hidden[:, :, None, None],

这种点级 mask 留下同一刚体的其他点历史时，往往可以从刚体关系恢复隐藏点。它没有保证整件工具或整个方块的历史消失。因此不能把本实验解释成“整对象历史缺失”的测试；也不能把补全更准直接当成未来预测更好。

判读范围：这 3 个窗口沿用已有公开案例，没有按本页补全分数重新挑选。seed 7 的 epoch 选项是在这些测试窗口上演示训练规则，并非恢复某次真实训练输入；默认选项才是原固定测试 mask。单点 / 单窗口误差不替代第一轮跨 episode 平均指标。
