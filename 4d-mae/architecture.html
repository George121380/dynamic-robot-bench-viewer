① 遮蔽的是轨迹历史

random：从当前可见场景表面选 K + Q 点，K 点提供历史，Q 点隐藏历史。

object：隐藏一个物体 / 工具的全部点历史；K 点来自其他实体，Q 个 query 来自被遮蔽实体。

Q 点的当前坐标仍是已知 query anchor；RGB 保留完整场景。物体 ID 只用于采样与诊断。

② 一个过去头，一个共享未来头

d̂(t) = F(p₀, t, M₀) − F(p₀, 0, M₀)

v4 在 FP32 中相减，保证 d̂(0) = 0。预测的是相对当前坐标的米制位移。

三项 Smooth L1 各自按窗口内有效 XYZ 标量归一化，再平均窗口；默认权重各 1/3。未来头一次查询 Q + K 点，再拆分两类输出。

③ 轨迹监督通过梯度影响策略

动作目标保留原生 ACT：标准化动作的 L1 + 10 × KL。完整 MAE 训练使用 completion="bounded"。

跨 rank 归约原始梯度后，辅助梯度在共享参数上的范数上限为主梯度的 0.1 倍（裁剪前）；点头单独更新。

选模仍看 raw action chunk MSE。默认每 100 updates 验证、每 1000 updates 保存。

配置入口与公平消融

两项部件开关作用于同一输入格式和同一融合位置；默认 MLP + cross-attention。切换部件不会改变其余共享参数的配对初始化。它们是数据与训练配方配对，并非等参数量。H（历史帧数）、K（输入点数）、Q（遮蔽 query 数）、S（动作 chunk 长度）由任务配置决定。

输入未来预测对照：将三个点损失权重设为 0 / 0 / 1；Tracks OFF 关闭辅助损失。completion="detached" 只训练点头，辅助梯度不回传观察编码。


当前信息边界与保留接口
图示对应当前 v4 / rgb_history=false 配方：仅输入当前 RGB 与当前状态，历史仅来自 flow。历史 v2 的 RGB-history 分支仍保留，但不在此配方启用。输入点特征为 [当前 XYZ / spatial scale，历史相对位移 / motion scale，物理时间，valid]，共 8 维；不输入未来轨迹或物体 ID。
Hook / Bowling 的点历史由当前 RGB-D 表面和仿真器刚体 pose 恢复，属于 oracle material tracks，包含过去被遮挡的表面；还不是视觉 tracker。全场景采样含物体、工具、机器人、桌面与背景，按候选像素均匀采样。推理取消人为物体遮蔽，保持 K 点输入预算。
predict_dynamics() 仍保留：预先给定的命令经过 command_encoder 后，仅进入动力学读出，使用时间 mask；本页的策略 MAE 不调用该接口，也不训练命令编码器。当前未来头学习专家轨迹中的观察条件续演，不代表已经学会动作条件动力学。
model/ 与 benchmark/ 平级；模型不读取任务名称。上游 ACT、既有 act_extension.py 和 patch 保持原样。当前 4D MAE 复用已有两个点头，未新增可学习参数。
